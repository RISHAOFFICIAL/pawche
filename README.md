# Pawché Luxury Pet Lifestyle Brand

This repository contains all the technical and operational artifacts for Pawché (pawche.store), a luxury pet lifestyle brand.

## Project Overview
Pawché is a high-growth luxury pet lifestyle brand operating in the premium e-commerce sector, catering to dog owners who prioritize status, aesthetics, and quality.

- **Aesthetic:** Obsidian Black and Radiant Gold.
- **Platform:** Shopify.
- **Fulfillment:** Dropshipping via DSers/AutoDS (AliExpress).

## Repository Structure

- `catalog/`: Contains the master Shopify import CSV and product catalog data.
  - `pawche_official_shopify_import_v4.csv`: The primary import file for Shopify.
  - `dsers_mapping_reference.csv`: Mapping for AliExpress fulfillment.
- `copy/`: Brand voice, email templates, SEO copy, and marketing calendars.
  - `brand_copy.json`: Core brand messaging.
  - `email_copy_v2.json`: Klaviyo/Shopify email automation copy.
  - `seo_v2.json`: SEO meta titles and descriptions.
- `guides/`: Operational playbooks and technical setup guides.
  - `technical_launch_guide.md`: Steps for store launch.
  - `EMAIL_SETUP_GUIDE.md`: Instructions for Klaviyo/Email setup.
  - `PAWCHE_FINAL_HANDOVER.md`: Comprehensive project summary.
- `policies/`: Store legal policies (Refund, Privacy, Terms, etc.).
- `pages/`: Content for About Us, Contact Us, and Size Guide pages.
- `assets/`: Marketing and branding assets.
  - `marketing_assets/`: Editorial-grade visuals for social and store use.

## Launch Status
The store is currently in the launch phase. All products have been curated and descriptions optimized. The technical infrastructure (Shopify, DSers, Klaviyo) is ready for activation.
